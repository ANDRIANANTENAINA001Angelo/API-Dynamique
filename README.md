# API-Dynamique
API Dynamique est une API REST Dynamique; Il permet de faire des requêtes de lecture, de création, de modification et de suppression dans tous les tables de tous votre base de données. Il permet donc de gagner du temps pendant le développement d’une application ou de plateforme car votre api est déjà prête à l’emploi directement

# To Run 
- git clone 
- php -S localhost:8000 
- Get http://localhost:8000/api-d/index.php?url=/
